# Product

## Register

product

## Users

Anyone exploring machine learning and data modeling and visualization notebooks. Visitors need to find an exercise, inspect its code and available datasets, and understand how the subjects are organized.

## Product Purpose

Present the ML and DMV exercise collection as a browsable, readable notebook library. Success means visitors can move from a subject to a problem, then read its notebook cells and locate its datasets.

## Brand Personality

Familiar, technical, clear. The interface should feel close to classic Jupyter so notebook readers can focus on the exercises.

## Anti-references

Avoid marketing-style landing pages and dark IDE themes. Do not add decorative UI that distracts from notebook content.

## Design Principles

- Use notebook conventions that readers already recognize.
- Keep code, rendered output, and dataset files easy to distinguish.
- Make the subject and problem hierarchy visible at every step.
- Support keyboard navigation, narrow screens, and reduced motion.

## Accessibility & Inclusion

Use accessible defaults, including semantic navigation, keyboard-operable controls, responsive layouts, readable contrast, and reduced-motion support.
